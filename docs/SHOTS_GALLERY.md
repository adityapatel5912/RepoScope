## 6. Explainable 3-Hop Blast Radius Simulator

Predicts the cascading blast radius of proposed code edits before modifying a single line of code. Categorizes impacted nodes into Hop 1 (direct callers), Hop 2 (transitive consumers), and Hop 3 (boundary API endpoints) with weighted risk points and test gap detection.

![Impact Simulator Panel](screenshots/v2/gallery/impact_simulator_panel.png)

## 7. Symbol-Level PR Impact & Contract Diff

Goes beyond raw git diffs to detect exact class, function, and interface contract breaks across pull request revisions. Flags breaking API route changes (/api/v1/users -> /api/v2/users), parameter type modifications (int -> UUID), affected downstream consumers, and untested modified symbols with a Critical 8/10 risk badge.

![PR Impact Symbols Panel](screenshots/v2/gallery/pr_impact_symbols_panel.png)

## 8. Hotspots, Bus Factor & Churn Time Machine
